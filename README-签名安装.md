# 像素放映厅 · iOS 壳工程

这是一个套壳 App：装到 iPhone 上之后，全屏打开家里的大厅页面 `http://192.168.0.78:18888/`。
本工程不带签名，需要你先在 GitHub 上（免费，用它的云端 Mac）构建出一个**未签名 IPA**，
再用你购买的证书自己签名安装。下面按顺序做就行。

包里的文件：

- `PixelArcade/` —— App 工程（用 GitHub 构建，不需要你打开看）
- `.github/` —— 自动构建的配置（**这个文件夹千万别漏传**，漏了就不会自动构建）
- `README-签名安装.md` —— 本说明

---

## 第一步：把工程传到 GitHub

1. 打开 github.com，登录（没有账号先注册一个，免费）。
2. 右上角 **+** → **New repository**：仓库名随便起（比如 `pixel-arcade-ios`），
   选 **Private（私有）**，点 **Create repository**。
3. 把下载到的本工程 zip 解压，在新仓库页面点 **uploading an existing file**，
   把解压出来的 **三个条目一起拖进上传页**：`PixelArcade` 文件夹、`.github` 文件夹、本 README。
   - 注意：`.github` 是以点开头的文件夹。Windows 资源管理器能直接看到；
     Mac 的访达里默认看不到，先在访达里按 **Command + Shift + .（句号键）** 把它显示出来再拖。
   - 文件夹要**整个拖**，不要一个个文件传。
4. 页面下方点 **Commit changes**，等上传完成。仓库里能看到 `PixelArcade` 和 `.github` 两个文件夹就对了。

## 第二步：等 GitHub 构建出 IPA

1. 打开仓库上方的 **Actions** 标签页。如果页面提示需要启用工作流，点绿色的启用按钮。
2. 左边选 **Build IPA**，右边点 **Run workflow** → 再点绿色 **Run workflow** 确认
   （如果第一步上传时已经自动触发了一次构建，就直接看那一次的结果，不用再点）。
3. 等 2～5 分钟，构建条变成**绿色对勾**就是成功了（黄色转圈是还在跑，红色叉是失败）。
4. 点进这次构建记录，拉到最下面 **Artifacts** 一栏，点 **PixelArcade-unsigned** 下载。
   下载下来是一个 zip，**解压后得到 `PixelArcade-unsigned.ipa`**，这就是待签名的安装包。

> 如果构建是红色叉：点进去看红色步骤的日志，把最后一段红字截图发给帮你做这个工程的助手，按日志改。

## 第三步：签名并安装到 iPhone（二选一）

签名要用你买证书时拿到的两个文件：**证书 `.p12`（带密码）** 和 **描述文件 `.mobileprovision`**。

### 办法 A：电脑上用爱思助手（推荐，步骤直观）

1. 电脑打开爱思助手，顶部 **工具箱** → **IPA 签名**。
2. 点 **添加证书**，选 `.p12` 文件并输入证书密码；再点 **添加描述文件**，选 `.mobileprovision`。
3. 点 **添加 IPA 文件**，选第二步下载的 `PixelArcade-unsigned.ipa`。
4. 勾选刚加的证书，点 **开始签名**，得到一个已签名的 IPA。
5. iPhone 用数据线连电脑，在爱思助手里把签好的 IPA **安装到设备**（或在 IPA 签名页直接选“安装到设备”）。

### 办法 B：手机上用「轻松签」

1. 在轻松签里依次导入：`.p12` 证书（输密码）、`.mobileprovision` 描述文件、`PixelArcade-unsigned.ipa`。
2. 在文件列表里长按 IPA → **签名** → 选刚导入的证书 → 签好后点 **安装**。
3. 如果安装后图标点开提示“未受信任的开发者”：到 iPhone
   **设置 → 通用 → VPN 与 设备管理**，找到对应的证书点 **信任**，再打开 App。

## 第四步：打开 App 前检查一遍

1. **证书里必须包含你这台 iPhone 的 UDID**。买证书时如果已经把这台手机的 UDID 报给卖家登记过，就没事；
   没登记的证书签完也装不上或装上闪退，需要找卖家补登记（或换包含你 UDID 的证书）。
2. 手机和 NAS 要连**同一个 WiFi/局域网**，App 打开就是大厅，和平时用浏览器打开的是同一个页面。
3. App 里已设置不自动锁屏、支持横竖屏、游戏声音可直接播放，打开就能玩。

## 改大厅地址（以后 NAS 的 IP 变了才需要）

打开 `PixelArcade/PixelArcade/AppDelegate.swift`，最上面 `HallConfig` 里这一行：

```
static let hallURL = URL(string: "http://192.168.0.78:18888/")!
```

把引号里的地址换成新地址，重新上传到 GitHub（覆盖同名文件即可），再走一遍第二、三步。

## 常见问题

- **装上点开就闪退 / 提示无法验证**：基本都是证书问题——证书过期、被吊销、描述文件和证书不配套，
  或者证书里没有这台手机的 UDID。先换/补证书，不要怀疑 App 本身。
- **打开是白屏或转圈，最后提示“连不上大厅”**：手机没和 NAS 在同一局域网、
  NAS 没开机/大厅没在运行、或者大厅 IP 变了（见上面“改大厅地址”）。
  先用手机浏览器开 `http://192.168.0.78:18888/` 验证能不能打开，浏览器打不开，App 也打不开。
- **签名时提示 App ID 不匹配**：本 App 的 bundle id 是 `top.hzswyz.arcadehall`。
  卖家给的描述文件如果是通配的（如 `*` 或 `top.hzswyz.*`）就没问题；
  如果是绑死某一个 App ID 的描述文件，要让卖家按这个 bundle id 出，或者把工程里的 bundle id 改成描述文件里那个（改 `project.pbxproj` 里两处 `PRODUCT_BUNDLE_IDENTIFIER`，改完重构建）。

## 注意事项（先说清楚的不确定点）

- 本工程是在 Linux 环境下按 Xcode 标准工程格式手写并逐项核对过引用关系的，
  **没能在本地真正跑一遍 xcodebuild 验证**（本地没有 Mac）。GitHub 的 macOS 机器是第一次真正的构建；
  万一第一次构建报错，按第二步的提示把日志发回即可对着改，这属于预期内的调试，不要慌。
- App 图标是用大厅现有的 512×512 网页图标放大生成的**占位图标**，放大后略糊。
  想换正式图标：用同尺寸的 PNG 替换 `PixelArcade/PixelArcade/Assets.xcassets/AppIcon.appiconset/` 里同名文件再重新构建即可。
- 因为大厅是自家局域网的 HTTP 地址，工程里放行了全部 HTTP 加载（ATS 全放行）。
  这只影响你自己签名自用的这个 App，它不会上架 App Store，不要拿这个包去提交审核。
- 证书签名装的 App 能用多久取决于你买的证书（一般按卖家说的期限）；证书到期或被吊销后，
  重新用新证书签一遍装上即可，工程和 IPA 不用重做。
